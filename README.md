# JCB-Dashboard
This project is an interactive Sales Analytics Dashboard developed in Power BI during my Data Analytics Internship. The dashboard transforms raw sales data into meaningful business insights, enabling users to monitor performance, analyze sales trends, and make data-driven decisions.

📌 Features
📊 Sales KPIs (Total Sales, Quantity, Transactions & Average Sales)
🏗️ Machine Model-wise Sales Analysis
📍 City-wise Sales Visualization using Map
📅 Monthly & Day-wise Sales Trends
💳 Payment Method Analysis
⭐ Customer Rating Insights
🎛️ Interactive Slicers for Dynamic Filtering
🛠️ Tools & Technologies
Power BI
Power Query
DAX (Data Analysis Expressions)
Microsoft Excel
📈 Dashboard Insights
Identifies top-performing machine models.
Tracks sales performance across different cities.
Analyzes customer payment preferences.
Monitors monthly sales trends and transaction patterns.
Provides interactive filtering for detailed business analysis.
📂 Project Objective

The objective of this project is to build an interactive Business Intelligence dashboard that helps stakeholders analyze sales performance, identify trends, and support better decision-making through data visualization.
